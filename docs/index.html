Build & Package (.deb)

一键构建与安装 SimpleScreenShot v1.0.4

源自仓库 build-deb.sh 与 README.md，支持 Ubuntu 20.04 / 22.04 / 24.04 及 Mint/MATE/XFCE。

./build-deb.sh sudo dpkg -i build-deb/simplescreenshot_1.0.4-1_amd64.deb sudo apt install ffmpeg xclip tesseract-ocr tesseract-ocr-chi-sim libappindicator3-1 pip3 install rapidocr onnxruntime
CLI Flags & Wayland Shortcut

命令行直达模式（源自 packaging/screencapture.1）

支持 --auto-quit 单次截屏退出与 --enter 框选后直达指定功能模块。

screencapture --auto-quit=true # 单次截屏后自动退出（推荐 Wayland 系统快捷键绑定） screencapture --enter tray # 静默启动并最小化至系统托盘 screencapture --enter long # 框选后直接进入滚动长截图拼接 screencapture --enter video # 框选后直接展开 MP4/GIF 录屏面板 screencapture --enter ocr # 框选后直接异步执行离线 OCR 识别 screencapture --enter qr # 框选后直接调用内置 quirc 识别二维码 screencapture --enter pin # 框选后直接钉在桌面置顶显示
